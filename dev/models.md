# Example models

Working models to read, run and copy. The core examples are the classic agent-based models; the zoo holds reference models from many fields, each one tested and documented; the gallery shows a figure from every zoo model.

- [Core examples](https://remipelloux.github.io/Modelly/dev/examples.html) 
 Boltzmann wealth, Schelling, Game of Life, Sugarscape, Epstein civil violence and more, with their full source.
- [Model zoo](https://remipelloux.github.io/Modelly/dev/zoo/index.html) 
 reference models from many fields, each a starting point, a teaching example and a regression test.
- [Gallery](https://remipelloux.github.io/Modelly/dev/gallery.html) 
 one figure per zoo model, made by running it with a fixed seed.
