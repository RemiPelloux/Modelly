\section{Conclusion}
\label{sec:conclusion}

\modelly{} keeps the agent-based programming model that Python modellers know and changes what
it costs to use it in research: array-backed and counted populations for speed, compiled loops
with pure-Python twins, and the experiment, calibration, sensitivity, provenance and
publication steps built on one seeding discipline. Its claims are measured in the open: against
Mesa~2.3, Mesa~3.5 and mesa-frames, with an agreement study over 100 seeds per variant; against its own previous release
before every new one; and with methods checked on problems whose answers are known. The
measurements also show where it does not help (a model written agent by agent runs between Mesa's speed and 4.6 times faster, depending on
how much of its time the framework's calls take, and hand-written numpy that gives up agent
objects is 1.8 to 4.4 times faster than its columns) and where its evidence is still thin (\cref{sec:threats}).

\section{Availability}
\label{sec:availability}

\cmd{pip install modelly-abm} installs \modelly{} (Python 3.12 or later), which is imported as
\code{modelly} and is free software under the Apache 2.0 licence. Compiled wheels are published
for Linux, macOS and Windows, and a pure-Python wheel elsewhere. Source, issue tracker, the 2,274 tests (97.7\% line coverage, measured by the test suite's coverage job)
and the benchmark harness are at
\href{https://github.com/RemiPelloux/Modelly}{\nolinkurl{github.com/RemiPelloux/Modelly}};
documentation, tutorials and the roadmap at
\href{https://remipelloux.github.io/Modelly/}{\nolinkurl{remipelloux.github.io/Modelly}}. The version described here is 1.3.2, which
contains the ABC-SMC correction of \cref{sec:validation}. The measurements used its library code, compiled on the
measurement machine with GCC~16.2, and the benchmark code of commit \code{627459a}, and Mesa's examples were ported with the codemod
fix of \cref{sec:portability}, which is not in 1.3.2; each
result file records the commit, the machine and the package versions. The data and scripts behind every table and figure
of this paper are in the repository's \code{paper/} folder (\cref{app:reproduce}). The repository
is archived by Software Heritage; the commit with the code, data and scripts of this paper is
\code{swh:1:rev:550458fe378d7f50147b}\allowbreak\code{1d6c4b5b1d49f3beddec}. To cite \modelly{}, use the
metadata in the repository's \code{CITATION.cff}.
