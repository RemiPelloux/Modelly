\section{Conclusion}
\label{sec:conclusion}

\modelly{} keeps the agent-based programming model that Python modellers know and changes what
it costs to use it in research: array-backed and counted populations for speed, compiled loops
with pure-Python twins, and the experiment, calibration, sensitivity, provenance and
publication steps built on one seeding discipline. Its claims are measured in the open: against
Mesa~2.3, Mesa~3.5 and mesa-frames, with an agreement study over 100 seeds per variant; against its own previous release
before every new one; and with methods checked on problems whose answers are known. Release
1.4 extends it beyond one process (split runs, a GPU backend, differentiable models) and
connects it to data, fields and the browser, each addition reported with what it measures
and where it falls short (\cref{tab:release14}). The
measurements also show where it does not help (a model written agent by agent runs between Mesa's speed and 4.6 times faster, depending on
how much of its time the framework's calls take; hand-written numpy that gives up agent
objects is 1.8 to 4.4 times faster than its columns; a split run on one laptop and a GPU at
20,000 agents gain little) and where its evidence is still thin (\cref{sec:threats}).

\section{Availability}
\label{sec:availability}

\cmd{pip install modelly-abm} installs \modelly{} (Python 3.12 or later), which is imported as
\code{modelly} and is free software under the Apache 2.0 licence. The release workflow builds
compiled wheels for Linux, macOS and Windows (x86-64 and ARM64) on the tag and a pure-Python
wheel for everything else (\cref{tab:determinism}). Source, issue tracker, the tests and the benchmark harness are at
\href{https://github.com/RemiPelloux/Modelly}{\nolinkurl{github.com/RemiPelloux/Modelly}};
documentation, tutorials and the roadmap at
\href{https://remipelloux.github.io/Modelly/}{\nolinkurl{remipelloux.github.io/Modelly}}.
% COUNTS-1.4.0: recount at the tag (pytest --collect-only; the gate's types stage)
The suite collects 2,984 tests, of which 55 skip without an optional library (CuPy, Ray,
optuna, xarray, a broker) or a browser, with 97.5\% line coverage measured by its coverage
job. The version described here is 1.4.0; the provenance of every measurement (commits,
machine, package versions and the Software Heritage identifier of the archived code) is in
\cref{app:reproduce}, and the data and scripts behind every table and figure of this paper
are in the repository's \code{paper/} folder. To cite \modelly{}, use the metadata in the
repository's \code{CITATION.cff}.
