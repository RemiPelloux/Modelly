\section{Conclusion}
\label{sec:conclusion}

\modelly{} keeps the agent-based programming model that Python modellers know and lowers the
cost of using it in research: array-backed and counted populations for speed, compiled loops
with pure-Python twins, and the experiment, calibration, sensitivity, provenance and
publication steps built on one seeding discipline. Its claims are measured against Mesa~2.3, Mesa~3.5 and mesa-frames, with an agreement study over 100 seeds per variant, and
with methods checked on problems whose answers are known. It also runs beyond one process
(split runs, a GPU backend, differentiable models) and connects a model to data, fields and
the browser, each capability reported with what it measures and where it falls short
(\cref{tab:scale}). The
measurements also show where it does not help (a model written agent by agent runs 1.05 to 4.8 times faster than on Mesa, depending on
how much of its time the framework's calls take; hand-written numpy that gives up agent
objects is 1.8 to 4.6 times faster than its columns; a split run on one laptop and a GPU at
20,000 agents gain little) and where its evidence is still thin (\cref{sec:threats}).

\section{Availability}
\label{sec:availability}

\cmd{pip install modelly-abm} installs \modelly{} (Python 3.12 or later), which is imported as
\code{modelly} and is free software under the Apache 2.0 licence. The release workflow builds
compiled wheels for Linux, macOS and Windows (x86-64 and ARM64) on the tag and a pure-Python
wheel for everything else (\cref{tab:determinism}). Source, issue tracker, the tests and the benchmark harness are at
\href{https://github.com/RemiPelloux/Modelly}{\nolinkurl{github.com/RemiPelloux/Modelly}};
documentation, tutorials and the roadmap at
\href{https://remipelloux.github.io/Modelly/}{\nolinkurl{remipelloux.github.io/Modelly}}.
At the tag, the suite runs 3,038 tests, of which 2,980 pass and 58 skip without an optional
library (CuPy, Ray, optuna, xarray, a broker) or a browser, with 97.3\% line coverage. The version described here is 1.4.2; the provenance of every measurement (commits,
machine, package versions and the Software Heritage identifier of the archived code) is in
\cref{app:reproduce}, and the data and scripts behind every table and figure of this paper
are in the repository's \code{paper/} folder. To cite \modelly{}, use the metadata in the
repository's \code{CITATION.cff}.
