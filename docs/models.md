# Example models

Working models to read, run and copy. The core examples are the classic agent-based models;
the zoo holds reference models from many fields, each one tested and documented; the gallery
shows a figure from every zoo model.

```{container} ml-hub
- [Core examples](examples.md)\
  Boltzmann wealth, Schelling, Game of Life, Sugarscape, Epstein civil violence and more, with their full source.
- [Model zoo](zoo/index.md)\
  reference models from many fields, each a starting point, a teaching example and a regression test.
- [Gallery](gallery.md)\
  one figure per zoo model, made by running it with a fixed seed.
```
