# Design reviews

the choice was made. The 1.3.0 roadmap asked for one page each for calibration (E1),
sensitivity analysis (E2), Studio (E5) and language-model agents (E7); the Studio decision is
in the [1.3.0 roadmap](../roadmap/1.3.0.md) (E5), the other three
are written here, after the fact, against the code as shipped in 1.3 and extended in 1.4.
