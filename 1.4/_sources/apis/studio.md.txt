# Studio

Modelly Studio, the browser app behind `modelly studio`. How to use it is in
[Modelly Studio](../studio.md).

| Module | Contents |
|---|---|
| `modelly.studio.config` | `StudioConfig` |
| `modelly.studio.params` | `Parameter`, `parameters_of` |
| `modelly.studio.loader` | `load_model_class`, `load_portrayal` |
| `modelly.studio.session` | `StudioSession` |
| `modelly.studio.timeline` | `GuardedRecorder`, `ReplayTimeline`, `track` |
| `modelly.studio.data` | series, agent table, figures and export files |
| `modelly.studio.recording` | `SessionRecording`, `Segment`, `literal` |
| `modelly.studio.exports` | `session_script`, `bundle_bytes`, `bundle_spec`, `script_name` |
| `modelly.studio.ensembles` | `ensemble_of`, `band_series`, `session_bands`, `reporter_operator` |
| `modelly.studio.assimilation` | `assimilate`, `FilterSettings`, `Assimilation`, `posterior_weights` |
| `modelly.studio.browser` | `ExperimentBrowser` |
| `modelly.studio.analyses` | `load_analyses`, `view_of`, `AnalysisView` |
| `modelly.studio.figures` | `band_figure`, `ess_figure`, `weights_figure`, `trajectory_figure`, `against_figure`, `series_figure` |
| `modelly.studio.scene` | `Scene`, `scene_of`, `encode`, `element_count` |
| `modelly.studio.assets` | `required_assets`, `missing_assets`, `fetch_assets` |
| `modelly.studio.mapview` | `MapWidget`, `MapView` |
